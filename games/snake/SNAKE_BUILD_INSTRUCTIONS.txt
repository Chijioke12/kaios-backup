6.  SNAKE DATA MODEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
snake = {
  segments: [{gx, gy}]   // grid positions, [0]=head
  direction: 'right'     // 'right','left','up','down'
  nextDir:   'right'     // buffered input
  tier: 1                // 1=worm, 2=serpent(≥15 len), 3=dragon(≥30 len)
  length: 3
  growing: 0             // segments to add on next move
}

Move timer: starts 250ms, speeds up by 5ms every food eaten, min 100ms.

On each tick:
  1. direction = nextDir (if not opposite)
  2. Calculate newHead = head + direction
  3. If newHead hits wall or self → death
  4. Prepend newHead to segments
  5. If newHead == food → eat(), growing++
  6. If growing > 0 → growing-- (don't remove tail)
  7. Else → remove last segment
  8. Rebuild sprite display (see section 8)

7.  SPRITE SELECTION LOGIC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Tier suffix: T = 't1' | 't2' | 't3'

HEAD:
  frameName = 'head_' + T + '_' + direction
  direction = snake.direction

BODY SEGMENT (index i, 1 ≤ i ≤ len-2):
  prev = segments[i-1], curr = segments[i], next = segments[i+1]
  fromDir = direction curr→prev
  toDir   = direction next→curr

  If fromDir == toDir (straight):
    frameName = (fromDir=='left'||fromDir=='right') ? 'body_h_'+T : 'body_v_'+T

  If turning (corner):
    Use this lookup table (fromDir_toDir → corner key):
      right_down → corner_tl
      right_up   → corner_bl
      left_down  → corner_tr
      left_up    → corner_br
      down_right → corner_br
      down_left  → corner_bl
      up_right   → corner_tr
      up_left    → corner_tl
    frameName = cornerKey + '_' + T

TAIL (last segment):
  dir = direction from second-to-last to last
  frameName = 'tail_' + T + '_' + dir

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Use a Phaser.Group of pre-created Sprite objects (pool of 50).
On each tick, reuse sprites from pool:
  sprite.frameName = frameName
  sprite.x = seg.gx * 16
  sprite.y = 28 + seg.gy * 16
  sprite.visible = true

Hide unused pool sprites. Never destroy/create — only reuse.

9.  FOOD SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Food types & weights (random weighted pick):
  apple         60%   score=10   grow=1   sound='eat'
  cherry        15%   score=20   grow=1   sound='eat'
  strawberry    10%   score=30   grow=1   sound='eat'
  golden_apple   8%   score=50   grow=2   sound='eat_golden'
  bonus_orb      7%   score=100  grow=0   sound='eat_bonus'

Spawn rules:
  - Never on snake body
  - Never on walls or power-ups
  - Random empty grid cell
  - Max 2 food items at once
  - Bonus orb despawns after 8 seconds with flashing animation (tween alpha 1→0.3 loop)

On eat:
  1. Play sound
  2. Spawn eat particles (5× ptcl_eat from atlas, tween up+fade)
  3. Show score popup (+10, +20 etc) at food position, tween up+fade
  4. Update score in HUD
  5. Spawn new food

10. POWER-UP SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Spawn: one power-up every 20 food eaten, random empty cell.
Despawn after 12 seconds (flash last 3 seconds).

  pu_ghost    duration=8s   effect: snake can pass through walls (wraps) + semi-transparent (alpha=0.6)
  pu_magnet   duration=6s   effect: food automatically moves toward snake head (tween food toward head each tick)
  pu_speed    duration=5s   effect: move timer = max(80, moveInterval-60)
  pu_shield   duration=8s   effect: one death blocked (snake flashes on would-be death, shield consumed)

Active power-up:
  - Show name + timer bar below HUD (small text + shrinking bar tween)
  - Play 'powerup' sound on collect
  - On expire: brief flash effect on snake

11. BIOME SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Biome changes every 500 points.
Order: lab → jungle → space → lava → lab ... (cycles)

Each biome uses a 15×17 tiled background:
  wall tiles:  top row (gy=0), bottom row (gy=16), left col (gx=0), right col (gx=14)
               frameName = biomeKey + '_wall'   (e.g. 'lab_wall')
  floor tiles: inner cells
               frameName = biomeKey + '_floor'
  deco tiles:  random ~12% of inner cells (seeded per biome entry)
               frameName = biomeKey + '_deco'

On biome change:
  1. Play 'biome_change' sound
  2. Show banner sprite (e.g. 'banner_lab') centered, tween in from top, hold 1.5s, tween out up
  3. Fade out current music, fade in new biome music (0.3s crossfade)
  4. Redraw background tiles

Biome music map:
  lab    → music_lab
  jungle → music_jungle
  space  → music_space
  lava   → music_lava

Snake collision with wall tiles: death (unless ghost active → wrap to opposite side)

13. SCORING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
score += food.score * combo
combo: eating food within 4 seconds of last eat increments combo (max ×5)
       combo resets on timeout, shown as "x2", "x3" etc in score popup

Persistent: localStorage('snakeEvolved_best')  = highest score ever
            localStorage('snakeEvolved_biome') = last chosen biome (menu selector)

HUD display:
  Left box:  score (live)
  Middle:    snake length
  Right:     biome icon + pause (||)

  DOWN  = 40   → snake nextDir = 'down'  (if current != 'up')

  BACK  = 8    → Menu: exit app    |  Game: pause         |  GameOver: back to menu
  CALL  = n/a
  F1    = 112  → pause (softkey left)
  F2    = 113  → mute music toggle (softkey right)

Softkey bar HTML overlay (position: fixed, bottom: 0, width: 100%):
  Left:  "PAUSE"   (grey)
  Center: ""
  Right: "MUTE" / "UNMUTE"   (grey)
  Style: background #111, height 20px, font-size 10px, color #aaa

15. DEATH SEQUENCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Play 'wall_buzz' (wall) or 'death' (self-collision)
2. Snake head flashes red (tween alpha 1→0 ×3, 80ms each)
3. Spawn 8× ptcl_spark at head position, explode outward
4. Camera shake: game.camera.shake(0.02, 300)
5. Wait 600ms
6. Fade music out (0.4s)
7. Play 'music_gameover'
8. Transition to GameOver state (pass score, best)
